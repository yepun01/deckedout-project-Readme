# Decked Out

Plateforme no-code pour créer et monétiser des jeux de cartes. Projet de fin d'études Epitech (EIP), en équipe de 4.

Ce dépôt ne contient que cette présentation. Le code vit dans les dépôts privés de l'équipe.

## Ma part

Toute l'algorithmie (TypeScript), tout le back-end et le moteur de jeu.

## Trois composants

**Éditeur desktop.** Création visuelle par nœuds, avec une assistance IA et de la collaboration en temps réel entre plusieurs utilisateurs.
Stack : Electron, React, TypeScript, Zustand, Yjs.

**Back-end cloud.** Authentification, multijoueur, stockage distribué, marketplace.
Stack : Node.js, TypeScript, PostgreSQL, Redis, WebSocket, Cloudflare R2.

**Runtime multi-plateforme.** Les jeux créés se jouent sur desktop, web et mobile.
Stack : Godot 4.4, GDScript.
